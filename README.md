# Campus Quest: The Learning Life
Online school-life simulation with player accounts, Student Mode, Teacher Mode, saves, and an administrator dashboard.

## Run
Node.js 18+: set ADMIN_USER and ADMIN_PASSWORD, then run npm start.

## Routes
/ = player game
/admin = administrator dashboard

## Deployment
Use a Node-compatible host with persistent storage, or replace the JSON database with a hosted database. Never commit your real admin password.
